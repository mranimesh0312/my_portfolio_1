# Animesh Ranjan — Portfolio

Premium interactive software engineering portfolio built with React, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Live Deployment

This project is ready for manual deployment on Vercel.

Recommended Vercel settings:

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`

## Sections

- Hero
- Engineering marquee
- About
- What I Build
- Projects
- Awards
- IIT Guwahati research
- Engineering stack
- Contact

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Local Setup

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
